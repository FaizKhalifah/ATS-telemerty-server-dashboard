# How to run
1. Clone this repository
2. enter npm install in the terminal
3. open the telemetry-server folder and then the server folder
4. run the Ets2Telemetry application file
5. Next, enter the ATS Telemetry dashboard folder
6. enter npm run dev in the terminal
7. open american / euro truck simulator
8. when the game is not paused, the telemetry will appear in the terminal
